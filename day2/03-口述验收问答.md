# Day 2 口述验收问答

> 用法：先遮住答案，用自己的话回答，再对照。  
> 目标：能解释对象从创建到销毁的完整过程。

## Q1. 类和对象有什么区别？

**答：** 类是设计图或类型，对象是根据类创建出来的具体实例。

```cpp
User user; // User 是类，user 是对象
```

## Q2. `public` 和 `private` 有什么区别？

**答：**

- `public` 成员可以在类外部访问；
- `private` 成员只能在类自己的成员函数中访问。

私有成员用于保护内部数据，外部应通过公有函数操作对象。

## Q3. 构造函数什么时候执行？

**答：** 在创建对象时自动执行。它负责初始化对象。

```cpp
User user("Alice");
```

执行这一行时会调用构造函数。

## Q4. 析构函数什么时候执行？

**答：**

- 栈对象：离开作用域时自动执行；
- 堆对象：执行 `delete` 时执行；
- 全局或静态对象：程序结束时执行。

## Q5. 为什么析构函数适合释放资源？

**答：** 因为对象生命周期结束时，析构函数会自动执行。可以把关闭文件、关闭 socket、释放内存等收尾工作放在析构函数中，降低忘记释放资源的风险。

## Q6. 栈对象和堆对象有什么区别？

**答：**

| 对比项 | 栈对象 | 堆对象 |
|---|---|---|
| 创建方式 | 直接定义 | `new` |
| 销毁方式 | 离开作用域自动销毁 | `delete` |
| 析构时机 | 作用域结束 | 执行 `delete` |
| 是否需要手动释放 | 不需要 | 需要 |

## Q7. `new` 和 `delete` 分别做了什么？

**答：**

- `new`：分配对象内存，并调用构造函数；
- `delete`：调用析构函数，并释放对象内存。

```cpp
Connection* ptr = new Connection(4);
delete ptr;
```

## Q8. 指针和引用有什么区别？

**答：**

- 指针保存地址，可以为空，可以重新指向；
- 引用是别名，必须初始化，通常不能改绑；
- 指针使用 `*` 和 `->`，引用像普通变量一样使用。

## Q9. 为什么对象使用 `.`，对象指针使用 `->`？

**答：**

- 对象本身使用 `.`：

```cpp
conn.show();
```

- 对象指针使用 `->`：

```cpp
ptr->show();
```

`ptr->show()` 等价于 `(*ptr).show()`。

## Q10. `this` 指针指向什么？

**答：** `this` 指向当前正在执行成员函数的对象。

```cpp
void rename(const std::string& name)
{
    this->name = name;
}
```

`this->name` 是当前对象的成员，`name` 是函数参数。

## Q11. 为什么函数参数有时使用 `bool&`？

**答：** 使用普通 `bool` 时，函数得到的是副本；使用 `bool&` 时，函数可以直接修改调用者传入的变量。

例如：

```cpp
void setTrue(bool& value)
{
    value = true;
}
```

调用后，外部变量也会被修改。

## Q12. 如果只 `new` 不 `delete`，会发生什么？

**答：** 堆对象可能不会执行析构函数，内存也不会释放，可能造成内存泄漏。

## Q13. 构造函数有哪些特点？

**答：**

- 函数名和类名相同；
- 没有返回类型；
- 创建对象时自动执行；
- 可以有参数；
- 可以有多个重载版本。

## Q14. 析构函数有哪些特点？

**答：**

- 函数名是 `~类名`；
- 没有返回类型；
- 没有参数；
- 不能重载；
- 对象销毁时自动执行；
- 常用于释放资源。
