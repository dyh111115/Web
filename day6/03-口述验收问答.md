# Day 6 口述验收问答

> 用法：先遮住答案，用自己的话回答，再对照。  
> 目标：能解释系统调用错误处理、常见 errno 和 man 手册的用法。

## Q1. 系统调用失败后一般先看什么？

**答：** 先看返回值。

例如：

- `open()` 失败返回 `-1`；
- `read()` 失败返回 `-1`；
- `bind()` 失败返回 `-1`。

确认失败后，再检查 `errno`。

## Q2. `errno` 是什么？

**答：** `errno` 是系统调用或库函数失败后设置的错误编号。

它不是“成功标志”。只有调用失败后，读取 `errno` 才有意义。

## Q3. 为什么不能用 `errno == 0` 判断成功？

**答：** 因为成功调用不保证把 `errno` 清零，`errno` 可能是之前失败留下的旧值。

正确方法是检查函数返回值：

```cpp
int fd = open(path, O_RDONLY);

if (fd != -1)
{
    // 成功
}
```

## Q4. `perror()` 有什么作用？

**答：** `perror()` 读取当前 `errno`，直接向标准错误输出自定义前缀和系统错误信息。

```cpp
std::perror("open");
```

可能输出：

```text
open: No such file or directory
```

## Q5. `strerror()` 有什么作用？

**答：** `strerror(errno)` 返回错误码对应的字符串，由程序决定如何输出或记录。

```cpp
std::cerr << std::strerror(errno) << '\n';
```

## Q6. `perror()` 和 `strerror()` 有什么区别？

**答：**

- `perror()` 直接输出错误信息；
- `strerror()` 只返回字符串，适合自行拼接日志。

## Q7. `ENOENT` 表示什么？

**答：** 表示文件或路径不存在，常见于 `open()` 打开不存在的文件。

## Q8. `EACCES` 表示什么？

**答：** 表示权限不足。例如没有权限读取文件、写入文件或绑定某个端口。

## Q9. `EINTR` 表示什么？

**答：** 表示系统调用被信号中断。

常见处理是重新尝试：

```cpp
do
{
    n = read(fd, buffer, sizeof(buffer));
}
while (n == -1 && errno == EINTR);
```

## Q10. `EAGAIN` 表示什么？

**答：** 表示当前暂时没有数据或资源，稍后可能可以继续。

在非阻塞 Socket 中，`recv()` 没有数据时经常返回 `EAGAIN`。

## Q11. `EAGAIN` 为什么通常不是致命错误？

**答：** 因为它表示“现在没有”，不表示连接已经损坏。事件驱动服务器应回到 `epoll_wait()`，等待下一次可读事件。

## Q12. `EADDRINUSE` 表示什么？

**答：** 表示地址或端口已经被占用，通常由 `bind()` 返回。

对应输出可能是：

```text
bind: Address already in use
```

## Q13. man 的 2 区和 3 区分别是什么？

**答：**

```text
2 区：系统调用
3 区：C 库函数
```

例如：

```bash
man 2 open
man 3 perror
```

## Q14. 在 man 页面中如何搜索错误码？

**答：** 输入：

```text
/EADDRINUSE
```

按 Enter 搜索，按 `n` 跳到下一个结果，按 `q` 退出。

## Q15. 为什么不能写死 errno 的数字？

**答：** 不同系统或平台上的错误码数字可能不同，应使用 `ENOENT`、`EINTR`、`EAGAIN` 等宏。

## Q16. 系统调用出错后的处理顺序是什么？

**答：**

```text
检查返回值
→ 检查或保存 errno
→ 判断错误能否恢复
→ 可恢复则重试或等待
→ 不可恢复则输出错误并清理资源
```

## Q17. 为什么 Web 服务器必须处理 `EAGAIN`？

**答：** 非阻塞 Socket 当前没有数据时会返回 `EAGAIN`。服务器不能把它当成连接损坏，而应回到事件循环等待下一次事件。

## 一分钟完整口述模板

> 今天学习了 Linux 系统调用的错误处理。系统调用通常通过返回值表示成功或失败，例如 `open()` 失败返回 `-1`。失败后 `errno` 会保存错误编号，但成功调用不保证把 `errno` 清零，所以必须先检查返回值。可以使用 `perror()` 直接输出错误信息，也可以使用 `strerror(errno)` 获取错误字符串。常见错误包括 `ENOENT` 表示文件不存在、`EACCES` 表示权限不足、`EINTR` 表示被信号中断、`EAGAIN` 表示暂时没有数据、`EADDRINUSE` 表示端口被占用。`EINTR` 通常需要重试，`EAGAIN` 在非阻塞 I/O 中应回到事件循环等待。通过 `man 2 open`、`man 2 bind` 可以查看函数原型、返回值和错误码。今天还用 `bind()` 复现了端口占用错误。
