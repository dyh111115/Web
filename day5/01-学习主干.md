## 4. 八个核心结论

1. **fd 是进程访问打开资源的整数编号，不是资源本身。**
2. **标准输入、标准输出、标准错误分别是 0、1、2。**
3. **文件、管道、Socket、epoll 实例都可以用 fd 表示。**
4. **进程是运行中的程序实例，拥有独立地址空间。**
5. **`fork()` 创建子进程，父子进程内存相互独立。**
6. **同一进程内的线程共享全局变量、堆和 fd。**
7. **多个线程同时修改共享数据会产生数据竞争。**
8. **`mutex` 用来保护临界区，`lock_guard` 负责自动加锁和解锁。**

## 7. 文件描述符

常用 fd：

```text
0：标准输入
1：标准输出
2：标准错误
3、4、5……：新打开的文件或 Socket
```

常见操作：

```cpp
int fd = open(path.c_str(), O_RDONLY);
ssize_t n = read(fd, buffer, sizeof(buffer));
close(fd);
```

`read()` 返回值：

```text
n > 0   读取到 n 个字节
n == 0  文件末尾或连接关闭
n == -1 读取失败
```

查看当前 shell 的 fd：

```bash
ls -l /proc/$$/fd
```

## 8. 进程和线程

进程与线程的关键区别：

| 对比项 | 进程 | 线程 |
|---|---|---|
| 地址空间 | 独立 | 共享所属进程 |
| 全局变量 | 不共享 | 共享 |
| 堆 | 不共享 | 共享 |
| fd | 默认不共享 | 同进程内共享 |
| 栈 | 独立 | 每个线程独立 |
| 创建开销 | 较大 | 较小 |
| 隔离性 | 较强 | 较弱 |

`fork()` 返回值：

```text
> 0：父进程中，返回子进程 PID
= 0：子进程中
= -1：创建失败
```

## 9. 数据竞争与互斥锁

错误情况：

```cpp
++counter;
```

可以大致拆成：

```text
读取 counter
加 1
写回 counter
```

两个线程可能同时读取相同的旧值，导致更新丢失。

正确方式：

```cpp
std::mutex counter_mutex;

{
    std::lock_guard<std::mutex> lock(counter_mutex);
    ++counter;
}
```

`lock_guard` 利用 RAII：

```text
构造时加锁
离开作用域时自动解锁
```
