## 4. 九个核心结论

1. **先检查返回值，再检查 `errno`。**
2. **`errno` 只在系统调用失败后才有意义。**
3. **成功调用不保证把 `errno` 清零。**
4. **`perror()` 直接输出错误信息。**
5. **`strerror(errno)` 返回错误信息的字符串。**
6. **`EINTR` 表示调用被信号中断，通常需要重试。**
7. **`EAGAIN` 表示暂时没有数据或资源，通常不是致命错误。**
8. **`EADDRINUSE` 表示端口已被占用。**
9. **`man 2` 查系统调用，`man 3` 查 C 库函数。**

## 7. `errno` 的基本用法

```cpp
#include <cerrno>

int fd = open(path, O_RDONLY);

if (fd == -1)
{
    int error_code = errno;

    std::cerr << "errno=" << error_code << '\n';
}
```

只有返回值表示失败时，才读取 `errno`。

错误写法：

```cpp
if (errno == 0)
{
    // 错误：成功调用不保证 errno 为 0
}
```

## 8. `perror()` 和 `strerror()`

```cpp
std::perror("open");
```

输出：

```text
open: No such file or directory
```

```cpp
std::cerr << std::strerror(errno) << '\n';
```

输出：

```text
No such file or directory
```

| 函数 | 用途 |
|---|---|
| `perror()` | 直接输出带前缀的错误信息 |
| `strerror()` | 返回错误字符串，由程序决定如何输出 |

## 9. `EINTR` 和 `EAGAIN`

`EINTR` 重试写法：

```cpp
do
{
    n = read(fd, buffer, sizeof(buffer));
}
while (n == -1 && errno == EINTR);
```

`EAGAIN` 判断：

```cpp
if (n == -1)
{
    if (errno == EAGAIN || errno == EWOULDBLOCK)
    {
        // 当前暂时没有数据
    }
}
```

简化理解：

```text
EINTR：被信号打断，重新调用
EAGAIN：暂时没有数据，等待下一次事件
```

## 12. 和 TinyWebServer 的关系

Web 服务器会频繁调用：

```text
socket()
bind()
listen()
accept()
recv()
send()
epoll_create()
epoll_ctl()
epoll_wait()
```

每个系统调用都可能失败，因此必须检查返回值。

后续非阻塞服务器中会遇到：

```text
EINTR
EAGAIN
EWOULDBLOCK
ECONNRESET
```

今天学习的是后续 Socket 和 epoll 代码能够正确排错的基础。
