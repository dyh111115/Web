## 二、核心知识回顾

### 1. 类与对象

使用 `class user` 把数据和操作数据的函数封装在一起。

类中的两个核心成员是：

```cpp
std::map<std::string, std::string> users;
std::vector<std::string> name;
```

它们分别承担不同职责：

| 成员 | 作用 |
|---|---|
| `users` | 保存“用户名 → 密码”的映射，支持快速查询和用户名唯一性判断 |
| `name` | 保存用户名，主要用于按添加顺序显示用户 |

这种设计说明：同一个问题可以使用多个容器配合解决，但必须保证数据一致。

### 2. 构造函数和析构函数

```cpp
user::user() {
    std::cout << "open user_manage" << std::endl;
}

user::~user() {
    std::cout << "close user_manage" << std::endl;
}
```

- 构造函数在对象创建时自动执行；
- 析构函数在对象生命周期结束时自动执行；
- `user manager;` 创建对象时输出 `open user_manage`；
- `main` 返回后对象销毁，输出 `close user_manage`。

通过这两个输出可以直接观察对象的创建和销毁过程。

### 3. map：按用户名查询密码

`std::map<std::string, std::string>` 保存键值对：

```text
用户名 → 密码
```

例如：

```cpp
users["Alice"] = "123456";
```

主要操作：

```cpp
users.find(userName);              // 查找
users.emplace(userName, password); // 插入
users.erase(it);                   // 删除
```

使用 `map` 的优点：

- 用户名和密码一一对应；
- 查询方便；
- 用户名天然不能重复；
- 适合实现账号管理类功能。

### 4. vector：保存显示顺序

`std::vector<std::string>` 保存用户名列表：

```cpp
name.push_back(userName);
```

添加用户时同步加入 `name`，删除用户时也要同步删除：

```cpp
auto nameIt = std::find(name.begin(), name.end(), userName);

if (nameIt != name.end()) {
    name.erase(nameIt);
}
```

`vector` 和 `map` 的数据必须保持一致：

- 添加成功时，两边都增加；
- 删除成功时，两边都删除。

如果只修改其中一个容器，就可能出现“能查询到但显示不出来”或“显示列表中有用户但查询不到”的问题。

## 三、主要功能的实现思路

### 1. 添加用户

核心要求：

1. 用户名不能为空；
2. 用户名不能重复；
3. `map` 插入成功后，才能把用户名加入 `vector`。

关键代码：

```cpp
auto result = users.emplace(userName, password);

if (!result.second) {
    std::cout << "用户名已存在" << std::endl;
    return false;
}

name.push_back(userName);
```

`emplace()` 返回一个 `pair`：

- `result.first`：指向元素的迭代器；
- `result.second`：是否插入成功。

当用户名已经存在时，`result.second == false`，并且原密码不会被覆盖。这比直接使用：

```cpp
users[userName] = password;
```

更适合“添加用户”功能，因为后者会覆盖已有密码。

### 2. 查询用户

实现方式：

```cpp
auto it = users.find(userName);

if (it == users.end()) {
    std::cout << "用户名不存在" << std::endl;
    return false;
}

std::cout << "用户：" << it->first << std::endl;
std::cout << "密码：" << it->second << std::endl;
```

知识点：

- `find()` 找不到时返回 `end()`；
- `it->first` 是用户名；
- `it->second` 是密码；
- 查询函数可以只返回是否找到，具体信息由函数内部打印。

### 3. 删除用户

删除需要同时处理两个容器：

```cpp
auto userIt = users.find(userName);

if (userIt == users.end()) {
    return false;
}

users.erase(userIt);

auto nameIt = std::find(name.begin(), name.end(), userName);

if (nameIt != name.end()) {
    name.erase(nameIt);
}
```

注意：

- `users.erase(userIt)` 删除映射；
- `std::find` 用于在 `vector` 中查找用户名；
- `name.erase(nameIt)` 删除列表中的用户名。

### 4. 修改密码

```cpp
auto it = users.find(userName);

if (it == users.end()) {
    return false;
}

it->second = password;
```

修改用户名对应的密码只需要修改 `map` 中的 `second`，因为用户名本身没有变化，所以不需要修改 `vector`。

### 5. 显示所有用户

```cpp
for (const auto& userName : name) {
    auto it = users.find(userName);

    if (it != users.end()) {
        std::cout << it->first << " " << it->second << std::endl;
    }
}
```

这里按 `vector` 中的顺序遍历用户名，再从 `map` 中取得密码。

## 四、多文件编程

### 1. 头文件 `user_manager.h`

头文件负责声明类，不放具体函数实现：

```cpp
#ifndef USER_MANAGER_H
#define USER_MANAGER_H

#include <map>
#include <string>
#include <vector>

class user {
private:
    std::map<std::string, std::string> users;
    std::vector<std::string> name;

public:
    user();
    ~user();

    bool adduser(std::string& name, std::string& password);
    bool finduser(std::string& name);
    bool removeuser(std::string& name);
    bool edituser(std::string& name, std::string& password);

    void showAllUsers() const;
};

#endif
```

必须注意：

```cpp
class user {
    // ...
};   // 这里必须有分号
```

头文件保护用于避免同一个头文件被重复包含：

```cpp
#ifndef USER_MANAGER_H
#define USER_MANAGER_H
// ...
#endif
```

### 2. 源文件 `user_manager.cpp`

源文件包含头文件并实现成员函数：

```cpp
#include "user_manager.h"
#include <algorithm>
#include <iostream>

bool user::adduser(std::string& userName, std::string& password) {
    // ...
}
```

成员函数定义必须带类名：

```cpp
user::user()
user::~user()
bool user::adduser(...)
bool user::finduser(...)
bool user::removeuser(...)
bool user::edituser(...)
void user::showAllUsers() const
```

不能写：

```cpp
user::bool adduser(...)
```

### 3. 程序入口 `main.cpp`

`main.cpp` 只负责：

- 创建 `user` 对象；
- 显示菜单；
- 读取用户选择；
- 调用成员函数；
- 控制程序退出。

它不应该直接操作 `users` 和 `name`，因为这两个成员是 `private` 的。

## 五、编译与运行

### 1. 编译

整个项目包含两个 `.cpp` 文件，因此编译时需要把它们一起交给 `g++`：

```bash
g++ -std=c++17 -Wall -Wextra -g main.cpp user_manager.cpp -o user_manager
```

各参数含义：

- `-std=c++17`：使用 C++17 标准；
- `-Wall -Wextra`：开启常用编译警告；
- `-g`：保留调试信息；
- `main.cpp user_manager.cpp`：参与编译和链接的源文件；
- `-o user_manager`：指定生成的可执行文件名称。

### 2. 运行

```bash
./user_manager
```

修改代码后，需要重新执行一次完整的 `g++` 编译命令，再运行程序。

### 3. 链接错误

如果只编译 `main.cpp`：

```bash
g++ main.cpp -o user_manager
```

由于缺少 `user_manager.cpp` 中的成员函数实现，可能出现：

```text
undefined reference to `user::user()'
undefined reference to `user::adduser(...)'
```

遇到 `undefined reference` 时，需要检查：

1. 函数是否已经实现；
2. 函数签名是否和头文件声明一致；
3. 所有相关 `.cpp` 文件是否都加入了编译命令。

## 六、今天遇到并解决的问题

### 1. 类定义末尾缺少分号

错误写法：

```cpp
class user {
    // ...
}
```

正确写法：

```cpp
class user {
    // ...
};
```

### 2. 成员变量和参数同名

如果成员叫 `name`，函数参数也叫 `name`，容易误解：

```cpp
name.push_back(name);
```

解决方式：

- 函数参数改名为 `userName`；
- 成员变量可以使用 `this->name` 明确表示。

```cpp
this->name.push_back(userName);
```

### 3. 成员函数缺少 `user::`

错误写法：

```cpp
bool adduser(...) { ... }
```

正确写法：

```cpp
bool user::adduser(...) { ... }
```

### 4. 重复定义同名局部变量

错误写法：

```cpp
auto it = users.find(name);
auto it = std::find(name.begin(), name.end(), name);
```

解决方式：

```cpp
auto userIt = users.find(userName);
auto nameIt = std::find(name.begin(), name.end(), userName);
```

### 5. 忘记 `std::`

`cout` 和 `endl` 属于标准库命名空间，应写：

```cpp
std::cout << "..." << std::endl;
```

### 6. 混淆编译错误和链接错误

- 编译错误：语法、类型、头文件、声明等问题；
- 链接错误：函数只有声明没有实现，或者某个 `.cpp` 没有参与编译。

遇到 `undefined reference` 时，先检查：

1. 函数是否实现了；
2. 函数签名是否与声明一致；
3. 对应的 `.cpp` 是否加入编译命令；
4. 编译命令是否包含所有需要参与链接的 `.cpp` 文件。

