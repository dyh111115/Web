# Day 5 口述验收问答

> 用法：先遮住答案，用自己的话回答，再对照。  
> 目标：能解释文件描述符、进程、线程、数据竞争和同步。

## Q1. 什么是文件描述符？

**答：** fd 是 Linux 进程访问已打开资源的整数编号，不是资源本身，而是操作系统提供的句柄。

```text
资源：文件、Socket、管道、epoll
fd：访问该资源的编号
```

## Q2. `0、1、2` 分别代表什么？

**答：**

```text
0：标准输入
1：标准输出
2：标准错误
```

之后打开的新文件通常从 `3` 开始分配，但具体编号由系统决定。

## Q3. 为什么 Socket 也可以用 fd 表示？

**答：** Linux 使用统一的文件描述符接口管理文件、管道、Socket 和 epoll 等资源。Socket 可以通过 fd 访问，并可以使用 `read()`、`write()`、`close()` 等操作。

## Q4. `open()` 返回什么？

**答：**

- 成功：返回非负 fd；
- 失败：返回 `-1`。

```cpp
int fd = open("/etc/passwd", O_RDONLY);
```

## Q5. `read()` 返回 `0` 和 `-1` 分别表示什么？

**答：**

- `0`：到达文件末尾，或者 Socket 对端关闭；
- `-1`：读取失败，需要进一步检查 `errno`。

如果 `read()` 返回正数，表示实际读取到的字节数。

## Q6. 为什么读取文本后要写 `buffer[n] = '\0'`？

**答：** 因为 `read()` 不会自动添加字符串结束符。`buffer` 是字符数组，如果不手动添加 `'\0'`，用 `std::cout` 输出时可能继续读取缓冲区后面的无效内容。

## Q7. `close(fd)` 做了什么？

**答：** 告诉操作系统当前进程不再使用该 fd 对应的资源。关闭后原 fd 不能继续使用，编号之后可能被新的资源复用。

## Q8. 如何查看一个进程打开了哪些 fd？

**答：** 使用 `/proc`：

```bash
ls -l /proc/$$/fd
```

`$$` 表示当前 shell 的 PID。输出中的编号就是 fd，箭头后面对应打开的资源。

## Q9. 程序和进程有什么区别？

**答：** 程序是磁盘上的可执行文件，进程是程序的一次运行实例。同一个程序可以运行多次，产生多个进程。

## Q10. `fork()` 的返回值是什么？

**答：**

```text
> 0：父进程中，返回子进程 PID
= 0：子进程中
= -1：创建失败
```

## Q11. 父子进程的内存共享吗？

**答：** 不共享。`fork()` 后父子进程拥有独立地址空间。子进程修改变量不会影响父进程中的同名变量。

Linux 通常使用写时复制提高效率，但逻辑上仍是独立内存。

## Q12. `waitpid()` 有什么作用？

**答：** 父进程等待指定子进程结束，并回收子进程的退出状态，避免产生僵尸进程。

## Q13. 进程和线程最大的区别是什么？

**答：** 进程之间资源独立，线程之间共享所属进程的地址空间、全局变量、堆和 fd。

每个线程拥有自己的栈、寄存器和程序计数器。

## Q14. 线程之间共享什么？

**答：** 同一进程中的线程共享：

```text
代码段
全局变量
堆内存
打开的文件和 fd
```

## Q15. 每个线程独有什么？

**答：** 每个线程独有：

```text
栈
寄存器
程序计数器
线程局部数据
```

## Q16. `std::thread` 的 `join()` 有什么作用？

**答：** `join()` 让当前线程等待目标线程结束。线程对象销毁前必须调用 `join()` 或 `detach()`，否则会导致 `std::terminate()`。

## Q17. 什么是数据竞争？

**答：** 多个线程同时访问同一份共享数据，并且至少有一个线程执行写操作，又没有同步机制，就会产生数据竞争。

例如：

```cpp
++counter;
```

在两个线程中同时执行时，可能出现读取旧值、更新丢失的问题。

## Q18. `mutex` 和 `lock_guard` 分别做什么？

**答：**

- `mutex`：互斥锁，保证同一时间只有一个线程进入临界区；
- `lock_guard`：在构造时自动加锁，离开作用域时自动解锁。

```cpp
{
    std::lock_guard<std::mutex> lock(counter_mutex);
    ++counter;
}
```

这利用了 RAII 思想。

## Q19. 为什么线程程序编译时要加 `-pthread`？

**答：** 因为线程功能需要链接对应的线程运行库。推荐命令：

```bash
g++ -std=c++17 -Wall -Wextra -pedantic -pthread thread_demo.cpp -o thread_demo
```

## Q20. Web 服务器为什么需要多线程？

**答：** 单线程一次只能执行一个处理流程。多线程可以让多个客户端请求并发处理，提高吞吐量。

但多个线程访问任务队列、连接状态、连接池等共享数据时，必须有同步机制。

## Q21. TinyWebServer 中哪些对象是 fd？

**答：**

```cpp
int listenfd;  // 监听 Socket
int connfd;    // 客户端连接 Socket
int epollfd;   // epoll 实例
```

它们都是文件描述符。
